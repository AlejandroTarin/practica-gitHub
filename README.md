Git es el software de control de versiones 
(creado por Linus Torvalds) que se utiliza 
de forma distribuida en el equipo local
de cada usuario.

GitHub es el servicio en la nube que aloja esos repositorios

En la práctica, se utilizan conjuntamente: GitHub sirve como 
el servidor central seguro para almacenar el código, mientras 
que los clientes usan el software Git en sus máquinas locales 
para subir (push) y bajar (pull) los cambios desde ese servidor.




Existen Repositorios Publicos y Repositorios Privados
